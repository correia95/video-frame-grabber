# Video Frame Grabber

Save any frame of a video as an image, entirely in the browser. React + TypeScript + Vite,
deployed as a static Cloudflare Worker.

- Drag-and-drop or file picker upload
- Scrub to an exact timestamp, grab that frame at full native resolution
- Export as PNG or JPEG
- Nothing is uploaded — capture happens via the HTML canvas API

## Dev

```
npm install
npm run dev
npm run build
npm run deploy
```
